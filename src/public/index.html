System Guarantees:

  • Immediate 202: API never blocks on slow destinations. Jobs queue instantly.
  • Exponential Backoff: 3 retries (delays: 1s, 2s, 4s).
  • Smart Error Separation: Retries 5xx & 429; stops immediately on permanent 4xx.
  • SSRF Defense: Validates DNS resolution against RFC1918, loopbacks, and cloud metadata (169.254.169.254).
  • Per-Destination Token Bucket: Throttles traffic per destination host.
  • Audit Logging: Every attempt records timestamp, status, outcome, duration, and error details in PostgreSQL.
